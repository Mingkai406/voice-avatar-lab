# Repository design references

The structure follows a readable research-software pattern: capability/status overview → runnable quick start → architecture and component sources → focused extension guides → contribution and validation process.

References reviewed when preparing this repository:
- [LivePortrait](https://github.com/KlingAIResearch/LivePortrait): explicit installation prerequisites, platform-specific instructions and model/source separation.
- [MLX Audio](https://github.com/Blaizzy/mlx-audio): model-oriented usage and examples.
- [LiveTalking](https://github.com/lipku/LiveTalking): separating avatar/runtime choices and operation instructions.
- [GitHub community profiles](https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/about-community-profiles-for-public-repositories): contribution, issue, security and licensing files.

This project implements its own documentation and integration code; it does not imply upstream endorsement. See THIRD_PARTY_NOTICES for adapted code and runtime asset provenance.
