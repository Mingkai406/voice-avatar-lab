# Changelog

## 0.1.0 — 2026-10-05

First standalone team-development release, extracted from the working VOICE Avatar Lab prototype.

- Phrase-preserving dialogue, editable per-gap silence and audio-clock playback events.
- Default local Qwen2.5 dialogue, Qwen3-TTS speech, DH_live portrait and separate LivePortrait experiment.
- Replaceable dialogue provider interface with an OpenAI-compatible adapter and scripted sample mode.
- Pinned source/model manifest, isolated setup, diagnostics and contributor documentation.
- Synthetic example audio, automated contract tests, public contribution templates and CI.

Neural output and model performance remain experimental. The release does not claim clinical validation, a production deployment or automatic full-duplex interaction.
